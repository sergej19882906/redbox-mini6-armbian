# Armbian для Redbox Mini 6 (v1)

Сборка Armbian 26.8.3 для ТВ-приставки **Redbox Mini 6 (v1)** — белорусский
операторский бокс (A1/Velcom) на **Allwinner H6**, клон Tanix TX6.

- Минимальный образ (server)
- Образ с легковесным десктопом **LXQt**

Сборка выполняется в GitHub Actions; готовый DTB (1 ГБ RAM) вживляется в образ
автоматически (`sun50i-h6-redbox-mini6.dtb`).
